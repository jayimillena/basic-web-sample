## John Doe — Portfolio (2026 Edition)

A modern, high-performance personal portfolio site built with pure HTML5 and custom CSS. Designed with a dark obsidian aesthetic, modern typography, glassmorphism UI elements, and glowing cyan/purple accent gradients.


## 🌟 Key Features

- **Zero-Dependency Architecture:** Pure HTML5 and CSS3 with no JavaScript frameworks or external CSS libraries required.
- **2026 Cyber-Obsidian Aesthetics:** Dark surfaces (`#080b11`), glassmorphism overlays with `backdrop-filter`, and neon cyan/purple design accents.
- **Modern Responsive Layouts:** Flexible grid structures using CSS Grid (`auto-fit`, `minmax`), Flexbox, and viewport-based fluid scaling.
- **Performance & Accessibility:** Lightweight markup, fast load times, smooth 60fps CSS animations, and semantic structure.
- **Generative CSS Visuals:** Pure CSS background patterns and animated visuals for project showcase previews.
